💰 Expense Tracker

A simple and interactive Expense Tracker Web Application built using Python and Streamlit. This project helps users record and manage their daily expenses through an easy-to-use interface.

✨ Features

- Add Expenses: Record daily expenses with relevant details.
- View Expenses: Display recorded expenses in a structured format.
- Expense Management: Store and manage expense records.
- Data Handling: Use Pandas to organize and process expense data.
- File Handling: Save expense records using text files.
- Error Handling: Handle invalid inputs and file-related errors.
- Expense Summary: View expense information in an organized way.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- File Handling
- Exception Handling (try-except)

🚀 How to Run the Project

Step 1: Clone the repository

git clone https://github.com/khu1412shi-cpu/Experience-tracker-.git

Step 2: Open the project folder

cd Experience-tracker-

Step 3: Install required libraries

pip install streamlit pandas

Step 4: Run the application

streamlit run app.py

The application will open in your default web browser.
